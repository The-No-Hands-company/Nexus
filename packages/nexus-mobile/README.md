# nexus-mobile

React Native / Expo scaffold for the Nexus mobile app roadmap.

## Run

```bash
cd packages/nexus-mobile
npm install
npm run start
```

## Current scope

- API base configuration
- Auth bootstrap (login)
- Local chat prototype UI

This package is intentionally minimal and acts as the foundation for full
feature parity work (servers/channels/messages/voice/push notifications).
