# SnakeED

Not built yet. This directory is a placeholder for the standalone editor
described in `../docs/ROADMAP.md` (v0.4 onward): live effect tuning first,
then a full level/character/environment editor linking `snake_engine` the
same way `game/` does.

If you're picking this up: start with v0.4 in the roadmap (an in-process
Dear ImGui overlay with hot-reloading `data/effects/*.json`), since it needs
no new executable target and immediately proves out editing the engine's
data-driven pieces live. The standalone `editor` executable in this
directory comes after that.
